## 本地執行
```bash
python -m pip install -r requirements.txt
python -m pytest -q
python scripts/update.py
python -m http.server 8000 --directory docs
```
瀏覽 `http://localhost:8000`。首次更新可能需數分鐘。無網路時頁面不會顯示虛構資料。

## GitHub Pages 免費部署
1. 在 GitHub 新建儲存庫（如 `tw-margin-radar`），上傳本 ZIP **解壓縮後的所有檔案**（含 `.github` 隱藏資料夾）。
2. 確認 Actions 已啟用。更新 workflow 已在檔案內明確要求 `contents: write`、`pages: write`，不需要擴大整個儲存庫的預設 workflow 權限。
3. `Actions > Update Taiwan bottom radar > Run workflow` 手動跑一次，檢查測試、抓取及 commit 是否成功。
4. `Settings > Pages > Build and deployment > Deploy from a branch`，Branch 選 `main`，資料夾選 `/docs`，儲存。
5. 等待 Pages 發布，網址通常是 `https://<你的帳號>.github.io/tw-margin-radar/`（以 GitHub 顯示的實際網址為準）。
6. 如果 Workflow 沒成功，先看 Actions 日誌。勿將空白或舊資料當成最新行情。

首次程式提交、手動執行及週一至週五 18:40 排程都會觸發更新。工作完成後會明確要求 Pages 重新建置，避免機器人提交資料後網頁沒有同步更新。並行更新依序執行；資料推送遇到遠端變更會安全失敗，不強制覆蓋。完全沒有近期可評分行情時工作會失敗並保留上次成功產生的檔案。

時間以台灣為準；手動於 16:00 前執行會保守略過當日歷史 K 線。官方上市報價日期直接解析 API 的民國日期，從不以抓取時間替代。融資原始端點未附可驗證來源日期，本版只標記抓取時間。手機表格可在區塊內左右滑動；頁面會隱藏超過七個日曆日的個股行情，並對超過 48 小時未產生新檔案提示核對日期。

## 資料與評分說明
- 當前總分上限 **65**（價格位置 30、跌幅 10、止跌 10、均線轉強 15）；不含融資與基本面，不能和預定完整版 100 分混用。
- 只要跌深不代表基本面良好；底部觀察、底部轉強都不是交易建議。
- 模擬回測：訊號當日收盤後，下一交易日收盤價模擬買入；20/60/120 交易日後收盤價模擬賣出；買賣手續費各 0.0855%，賣出交易稅 0.3%，未計滑價。實際費率可能不同。
- 研究用途；未處理生存者偏差與股價還原等因素，績效可能高估或失真。
