# Rust 融資風險與起漲雷達（待審查）

## 範圍與現有專案檢查

本分支起點為 `63902b6ecb40a3bbbc4fcb73b2dd0a5f508fad7e`，獨立新增 Rust 批次與 `/rust/` 靜態頁面。既有 Python、V2 首頁與自動更新 workflow 不修改。本分支沒有新增部署觸發器，不合併、不部署正式環境。

既有來源與功能已做程式審查：TWSE OpenAPI 上市當日報價、融資原始資料；Yahoo 非官方歷史 K 線；最多 65 分的價格評分；搜尋、階段篩選、重新整理、手機橫向表格及歷史事件回測。融資原始資料未參與評分，缺少同日行情/融資完整性閘門；最多 75 檔輪替抓取並非每日全市場。既有 Actions 排程設定台灣 18:40；最近查到的更新實際在台灣 2026-10-31 00:48 執行，資料中的上市報價日期是 10/29，故「workflow 成功」不等於「最新交易日齊備」。Actions 排程可能延遲，不適合當嚴格準時保證。

## 官方來源與單位

所有端點以指定交易日查詢，回應內日期必須完全相符，從不以查詢參數或抓取時間冒充來源日期。

| 資料 | 官方端點 | 主要欄位 |
|---|---|---|
| 上市價格 | `www.twse.com.tw/exchangeReport/MI_INDEX?response=json&date=YYYYMMDD&type=ALLBUT0999` | 證券代號、收盤價、成交股數 |
| 上市融資 | `www.twse.com.tw/exchangeReport/MI_MARGN?response=json&date=YYYYMMDD&selectType=ALL` | 前日餘額、買進、賣出、現金償還、今日餘額、次一營業日限額，單位張 |
| 上櫃價格 | `www.tpex.org.tw/www/zh-tw/afterTrading/dailyQuotes?date=YYYY/MM/DD&id=&response=json` | 代號、收盤、成交股數 |
| 上櫃融資 | `www.tpex.org.tw/www/zh-tw/margin/balance?date=YYYY/MM/DD&id=&response=json` | 前資餘額(張)、資買、資賣、現償、資餘額、資限額 |
| 官方年度日曆 | `www.twse.com.tw/holidaySchedule/holidaySchedule?response=json&queryYear=民國年` | 明確休市、放假、補假、無交易日期；排除開始/最後交易日里程碑 |

上市融資報表的融資/融券欄名重複，必須核對融資區塊的完整欄位前綴，避免把融券當融資。兩市場均檢查：今日餘額＝前日餘額＋買進－賣出－現金償還。所有數字必須有限、非負；不得用缺值補零；非整數張數拒收。新 schema、重複代碼、損壞歷史檔案、不同交易日資料一律失敗。官方來源校正若與已存快照不同，拒絕覆寫，需人工建立新版本審查。

「使用率」不是整戶擔保維持率：TWSE 只提供次一營業日限額，這裡明示今日融資餘額／次一營業日限額的**代理值**；TPEX 為資餘額／資限額。限額 0 時使用率為 null。全市場整戶擔保維持率持續為 null。

固定十檔觀察名單：2330 台積電、2454 聯發科、3008 大立光、3017 奇鋐、3533 嘉澤、3661 世芯-KY、5269 祥碩、3529 力旺、5274 信驊、6510 精測。這是可修改的高價股觀察名單，**不是聲稱當日股價最高十檔**。

## 評分與候選

每檔需要連續 21 個交易日的同日行情/融資。相鄰日「前資餘額」須等於前一天的資餘額，否則排除。完整交易日必須連續，不能將缺日壓成連續 K 線。

| 因子 | 分數 |
|---|---:|
| 本日融資較前20日高點減少至少10% | +30 |
| 近5日收盤低點未跌破前16日收盤低點 | +20 |
| 收盤站上5日均線，均線及股價轉升 | +20 |
| 成交量達前20日均量1.2倍 | +10 |
| 融資使用率低於20%；20%至40% | +10；+5 |
| 收盤站上20日均線 | +10 |
| 價跌融資增 | -30 |
| 融資使用率達60% | -20 |

總分限制在 0–100。候選依總分排序，同分依市場/代碼固定順序。每檔顯示全部加扣分與使用率定義。「去槓桿後轉強」需減融資、止跌、均線轉升三條件同時成立；價跌融資增或使用率達60%標「融資風險」。每日前十是研究排序，可能全部僅「觀察」，不強迫湊出十個買進訊號。

`config/radar.json` 的 `all_market=true` 啟用上市櫃擴充模式：資料下載本來就涵蓋兩市場全表，無須逐股增加 API。四碼、非 0 開頭的報價股票經融資/歷史完整性篩選後排名，並列出所有排除原因與覆蓋數，至少十檔可評分才發報告；不宣稱無融資資格、停牌、下市、缺資料股票也已評分。

## 使用

從 repo 根目錄，Rust 1.99.1；Linux 建議在 CI 編譯靜態 musl 執行檔，禁止在交易 VM 編譯。

```sh
cargo test --manifest-path rust-radar/Cargo.toml --locked
cargo run --manifest-path rust-radar/Cargo.toml --locked -- import --from 2026-09-01 --to 2026-10-30
cargo run --manifest-path rust-radar/Cargo.toml --locked -- preview --date 2026-10-30 --output preview/data/latest.json
cargo run --manifest-path rust-radar/Cargo.toml --locked -- backtest --hold 5 --output var/backtest.json
```

歷史補抓不發布，只記錄實際補抓時間並標 `historical_import=true`。每次最多370日；可中斷再執行，已存日跳過。官方歷史資料如果沒有可驗證的回應日期、欄位、餘額等式，就停止；不偷偷回退 Yahoo 或舊日期。不建議頻繁整段重抓。

`prices` 僅在台灣16:00後保存兩市場當日價格；`update` 僅在18:00後下載四張同日報表、儲存完整快照，再檢查21交易日視窗並產出前十。未滿21日、十檔缺任何一檔時不發不完整報告。每日 raw 與正規化 history 保留作研究，當日只建立一份不可變 report；`latest.json` 原子更新並禁止倒退日期。崩潰後重跑可修復「每日報告已存、latest 指標尚未更新」的狀態。

臨時颱風停市不一定會更新年度日曆：由管理者核對交易所公告後加入 `closed_dates`。未加入前採失敗拒發，不推測成休市或發布舊日期的新報告。

## 回測界線

訊號只使用指定日以前的快照，不使用未來價格評分。個股事件不重疊；最早下一交易日收盤模擬進場，持有指定交易日數後收盤出場。即時快照還要求資料實際取得時間早於模擬進場收盤；歷史補抓沒有當時公布時間，只能標示「假設次交易日可取得」的回溯研究。

買賣費各0.1425%、賣出稅0.3%、每邊滑價0.1%為可檢查的研究假設，非個人實際費率。結果是個股事件平均報酬，不是資金加權投組績效。尚未處理除權息還原、完整下市樣本、歷史名單成分及樣本外驗證，不能據此宣稱策略有獲利能力。

## 手機頁面

`docs/rust/` 使用獨立資料格式，不取代 V2。手機單欄卡片、搜尋/訊號篩選、手動刷新、每檔可展開評分；來源限官方 HTTPS 並顯示 SHA256。載入失敗清空排名；超過兩日舊交易日顯示警告；歷史補抓顯示研究限制。頁面無測試行情假扮即時資料。原始 API 及私有 state 不放在網站根目錄。
